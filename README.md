# 🏠 House Expense Predictor

A simple and interactive **House Expense Predictor Dashboard** built using Python, Machine Learning, Flask, Pandas, NumPy, Scikit-learn, HTML, CSS, and JavaScript.

The project predicts the estimated monthly house expense based on different household parameters such as house size, number of bedrooms, number of people, electricity usage, and water usage.

---

## 📌 Project Overview

The **House Expense Predictor** is a beginner-friendly Machine Learning project developed as part of a **Python for Data Science** project.

The system uses **Linear Regression** to predict house expenses from a dataset containing different household characteristics.

The project also provides a web-based dashboard where users can enter house information and instantly get an estimated expense.
